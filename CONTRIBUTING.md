# Contributing

1. Fork and create a focused branch.
2. Do not commit OAuth tokens, Dida config, task IDs, logs, or session files.
3. Run `npm install` and `npm run check` before opening a pull request.
4. Keep public user interaction natural-language first; `/todos` is the only public Todo slash command.
5. Preserve the Repository invariant: source work cannot complete before a pending human-acceptance Todo exists.
